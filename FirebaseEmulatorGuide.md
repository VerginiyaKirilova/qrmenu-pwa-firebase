# Ръководство за работа с Firebase Emulator

Това ръководство ще ви помогне да разберете как да работите с Firebase Emulator и как да тествате приложението локално.

## 1. Стартиране на Firebase Emulator

Firebase Emulator е локална версия на Firebase услугите, която ви позволява да тествате приложението си без да използвате реалната Firebase инфраструктура.

За да стартирате Firebase Emulator, изпълнете следната команда в основната директория на проекта:

```bash
firebase emulators:start
```

Това ще стартира всички емулатори, конфигурирани във вашия `firebase.json` файл, включително:
- Firestore емулатор на порт 8082
- Auth емулатор на порт 9099
- Functions емулатор на порт 5001
- Storage емулатор на порт 9199
- Hosting емулатор на порт 5000

## 2. Добавяне на тестови данни в Firestore

За да тествате приложението, трябва да добавите тестови данни в Firestore емулатора. Има два начина да направите това:

### Използване на UI интерфейса на емулатора

1. Отворете UI интерфейса на емулатора в браузъра: http://localhost:4000
2. Кликнете върху "Firestore" в навигацията
3. Използвайте интерфейса, за да създадете колекции и документи

### Използване на seed скрипта

В проекта има скрипт, който автоматично добавя тестови данни в Firestore емулатора. За да го използвате:

1. Уверете се, че Firebase емулаторът е стартиран
2. Уверете се, че използвате Node.js версия 10 или по-нова (скриптът използва firebase-admin v9.12.0)
3. Отворете нов терминал
4. Навигирайте до директорията `tools`:
   ```bash
   cd tools
   ```
5. Изпълнете скрипта за добавяне на данни:
   ```bash
   npm run seed-data
   ```

Този скрипт ще добави следните данни:
- Ресторант с ID "R123"
- Маса с ID "T7" в ресторанта
- Категории меню (Appetizers, Main Courses, Desserts, Drinks)
- Няколко елемента от менюто във всяка категория

## 3. Структура на данните в Firestore

Приложението очаква следната структура на данните в Firestore:

```
restaurants/{rid}                      # Документ за ресторанта
restaurants/{rid}/tables/{tableId}     # Документи за масите
restaurants/{rid}/menuCategories/{categoryId}  # Документи за категориите в менюто
restaurants/{rid}/menuItems/{itemId}   # Документи за елементите в менюто
```

Където:
- `{rid}` е ID на ресторанта (например "R123")
- `{tableId}` е ID на масата (например "T7")
- `{categoryId}` е ID на категорията (например "appetizers")
- `{itemId}` е ID на елемента от менюто (например "french-fries")

## 4. Тестване на приложението
[FirebaseEmulatorGuide.md](FirebaseEmulatorGuide.md)
След като сте стартирали емулатора и сте добавили тестови данни, можете да тествате приложението:

1. Стартирайте приложението в отделен терминал:
   ```bash
   cd web
   npm run dev
   ```

2. Отворете приложението в браузъра: http://localhost:5173/menu?rid=R123&table=T7

Приложението трябва да зареди данните от Firestore емулатора и да покаже менюто на ресторанта.

## 5. Отстраняване на проблеми

Ако приложението не може да намери данните в Firestore емулатора, проверете следното:

1. Уверете се, че Firebase емулаторът е стартиран
2. Уверете се, че сте добавили тестови данни с правилната структура
3. Проверете конзолата на браузъра за грешки
4. Уверете се, че портовете в `firebase.ts` съвпадат с портовете в `firebase.json`

Най-честата грешка е несъответствие между портовете. В `firebase.ts` трябва да имате:

```javascript
connectFirestoreEmulator(firestore, 'localhost', 8082);
```

А в `firebase.json` трябва да имате:

```json
{
  "firestore": {
    "port": 8082
  }
}
```

## 6. Важни файлове

- `web/src/utils/firebase.ts` - конфигурация на Firebase и връзка с емулаторите
- `tools/seed-data.js` - скрипт за добавяне на тестови данни
- `firebase.json` - конфигурация на Firebase емулаторите
- `web/src/pages/MenuPage.tsx` - основната страница, която зарежда данни от Firestore

## 7. Заключение

Работата с Firebase Emulator ви позволява да тествате приложението локално, без да използвате реалната Firebase инфраструктура. Това е полезно за разработка и тестване, тъй като не консумира реални ресурси и не изисква интернет връзка.

Не забравяйте да добавите тестови данни в емулатора, преди да тествате приложението!
